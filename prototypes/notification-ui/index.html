상시 표시와 임계값 알림, 어떤 모양이어야 하나

세 변형을 ?variant=A|B|C로 전환합니다. 위 칩으로 세션 상태를 바꾸면 세 화면이 함께 바뀝니다. 셰이드는 Pixel 계열 다크, 설정 화면은 Material 3 라이트를 흉내 냈습니다. 실제 색은 기기의 다이내믹 컬러를 따릅니다.

고정된 결정: 상시 표시에는 액션 없음 · 임계값 알림은 별도 heads-up이며 액션 버튼은 세션 알림 끄기 하나 · 알림 탭은 설정 화면 · 잠금 중에는 알림을 보내지 않음 · 재알림 기본 15분. 변형이 다투는 것은 정보 배치와 문구뿐입니다.
