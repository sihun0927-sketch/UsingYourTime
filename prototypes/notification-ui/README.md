# PROTOTYPE: 상시 표시 + 임계값 알림 UI 시안

**버리는 코드.** 티켓 #7의 질문 하나에 답하기 위한 HTML 목업이다. 프로덕션에 옮기지 않는다.

## 질문

상시 표시(진행 중 알림)와 임계값 알림(heads-up)에 **어떤 정보를 어디에, 어떤 문구로** 놓을 것인가.
설정 화면 상단 상태 카드(상태·연속 사용 시간·버튼 1개)의 배치도 함께 본다.

고정된 결정(#4, #9, #14)은 변형 사이에서 바뀌지 않는다: 상시 표시 액션 없음, 임계값 알림은 별도 알림이며
액션 버튼은 "세션 알림 끄기" 하나, 탭은 설정 화면, 잠금 중 알림 없음, 재알림 15분.

## 실행

`index.html`을 브라우저에서 연다. 빌드 없음.

- `?variant=A|B|C` 또는 하단 플로팅 바 / `←` `→` 키로 변형 전환
- 상단 칩으로 세션 상태 전환: 임계값 전 / 첫 알림 / 재알림 / 세션 알림 끄기 이후 / 유예 중(잠금)

## 변형

| 키 | 이름 | 상시 표시 | 임계값 알림 | 상태 카드 |
|---|---|---|---|---|
| A | 시계형 | 헤더 chronometer `47:12` + 본문 한 줄 | "n분째" 제목 + 다음 알림 예고 | 항목 3줄 목록 |
| B | 진행바형 | 제목 "47분 / 30분" + 진행 막대 | BigText 설명문 | 큰 숫자 + 원형 게이지 |
| C | 한 줄형 | 제목 "47분" 크게, 본문 없음 | 제목 한 줄, 본문 없음 | 한 줄 배너 |

각 변형 아래 "구현 메모"에 표준 `Notification.Builder` 템플릿으로 되는 것과 커스텀 `RemoteViews`가 필요한 것을 적었다.
